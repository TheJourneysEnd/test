# Сборка

1. Склонировать репозиторий и зайти:
   ```bash
   cd test
   ```
2. Запустить контейнеры в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```
3. После запуска проверить результат:
   ```bash
   curl http://localhost:7676
   ```
   *P.S. При желании порт можно изменить в файле `docker-compose.yaml`.*

# Nginx схема

[Пользователь] ──( Порт 7676: HTTP )──► [Nginx] ──( Внутренняя сеть )──► [Flask Backend] (Порт 8080)
